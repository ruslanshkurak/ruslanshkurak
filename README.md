## 🚀 About Me

I'm a Backend Developer focused on building high-performance systems, microservices, and automation tools using **Go** and **Python**. I'm passionate about distributed systems, async data processing, and clean architecture.

* 🏗️ **Backend & Microservices:** REST / gRPC API design, microservices architecture, and clean code.
* ⚙️ **Event-Driven & Async:** Experience with **Kafka** and asynchronous data pipelines.
* 📊 **Data & Storage:** Working with PostgreSQL, ClickHouse, Redis, and S3 (MinIO).
